# API Consulta

Script en Python para consumir APIs REST públicas y filtrar datos.

## ¿Qué hace?
- Consulta usuarios desde una API REST
- Consulta comentarios de posts
- Filtra posts por usuario específico
- Muestra resultados en formato legible

## Tecnologías
- Python 3.x
- requests

## Uso
```bash
python api_consulta.py
```

## Ejemplo de output
```
Leanne Graham | Sincere@april.biz
Ervin Howell | Shanna@melissa.tv
...
```
